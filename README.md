# Piyush Kumar – Full‑Stack Developer Portfolio

A modern single‑page portfolio website for showcasing my work as a Full‑Stack Developer (MCA), with a focus on JavaScript, Node.js, and Generative AI projects.

---

## 🌐 Live Demo

- **URL:** https://piyushdev-ai.netlify.app/

---

## ✨ Features

- Single‑page layout with smooth scroll navigation (Home, About, Skills, Projects, Certifications, Experience, Contact).
- Hero section with:
  - Name, role, and short summary.
  - Highlight of interest in Full‑Stack and Generative AI.
- About section with:
  - Short bio and goals as an MCA‑level developer.
  - Profile image with glowing effect.
- Skills / Tech stack:
  - Frontend: HTML, CSS, JavaScript, React.
  - Backend: Node.js, Express, REST APIs.
  - Databases / Tools: Firebase, Git/GitHub, Netlify, and others.
- Projects section:
  - Cards showcasing key projects, including the **Advanced Todo App** with Firebase Auth + Firestore sync.
- Certifications section:
  - Google Cloud: Introduction to Generative AI Studio.
  - Databricks for Generative AI (Simplilearn).
  - GenAI Data Analytics Job Simulation (TATA Forage).
- Experience / Timeline section.
- Contact section with form, email and social links.
- Scroll‑to‑top button.

---

## 🧱 Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript  
- **Styling:** Custom CSS with glassmorphism, glows, responsive grid layout  
- **Icons & Fonts:** Font Awesome, Google Fonts  
- **Deployment:** Netlify (static hosting)
